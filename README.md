## 三网 CN2 GIA 是什么，为什么要在意它

简单说：**三网 CN2 GIA VPS，就是电信、联通、移动三大运营商去程和回程都走中国电信 CN2 GIA 高端精品线路的服务器**。

CN2 GIA（Global Internet Access）是中国电信旗下质量最高的一条骨干网，特点是低延迟、抗拥堵、晚高峰不掉速。普通国际线路走的是 163 骨干网，晚上一到八九点就开始丢包卡顿；CN2 GT 会路由绕弯；CN2 GIA 是从数据中心到你家，走最短最快的路。

"三网"的意思是电信、联通、移动都覆盖，不是只优化一家。这个很要紧，因为有些服务商只做电信 GIA，联通移动用户体验差很多。

**Q：IP 被墙了怎么办？**

每 15 天可以免费申请换一次（仅限 IP 在敏感地区不可用的情况）。其他情况换 IP 收 $5。相比很多商家"换 IP 不管"，这个政策实用多了。

**Q：Eyeball（EB）和 Premium（Pro）区别是什么，有必要买 Pro 吗？**

Pro 系列三网 CN2 GIA 双向优化，这是写死在合同里的，不会因为攻击或成本原因切换路由。EB 系列走 CMIN2，性价比高，联通移动用户体验通常也不错，但线路稳定性保障不如 Pro。电信用户、对线路稳定性是刚需的，建议直接上 Pro。预算有限、联通移动为主，EB 是合理选择。

**Q：新注册账号能马上下单吗？**

DMIT 对新注册账号有一个等待期（一般 7 天），才能下单购买。如果你有购买计划，提前几天注册好账号。

**Q：退款政策怎么样？**

3 天内且流量使用不超过 30GB，可以全额退款；1 个月内按剩余价值比例退款（扣除支付网关手续费）。试用期内不满意可以退，门槛不算高。
